# Meslo LG

Meslo LG is a customized version of Apple’s Menlo-Regular font
(which is a customized Bitstream Vera Sans Mono).

Nerd Fonts uses a patched version by opeik: https://github.com/opeik.

Upstream: https://github.com/andreberg/Meslo-Font

Version: 1.21
